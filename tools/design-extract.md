# design-extract

Repository or runtime: `Playwright-based extractor`.

Renders every reference route, scrolls lazy content, extracts computed styles, component patterns, and animation keyframes, and writes design_system.json.

## Contract

Input and output are validated before the next node consumes them. Keep the tool replaceable: alternatives must satisfy the same artifact schema.
