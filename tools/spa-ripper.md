# SPA-Ripper

Repository or runtime: `github.com/greenman9909-cmd/spa-ripper`.

Default acquisition tool. Runs `spa-ripper --target URL --out DIR --extract structure,endpoints,tokens,stack --depth 3 --render`. Produces structure.json, endpoints.txt, design_tokens.json, sections.md, and mirror/. Fallback: SiteMap-X, HAR, manual paste, screenshots.

## Contract

Input and output are validated before the next node consumes them. Keep the tool replaceable: alternatives must satisfy the same artifact schema.
