# Wiring Contract

Every file write is validated by a resolver before it lands. The resolver map is updated on every write. Checked reference types are imports, images, routes, API calls, tokens, environment variables, i18n keys, and components. Create trivial missing referents, wire unfinished features to a visible `coming soon` placeholder, correct typos, and halt on unresolvable references. No file ships with an unresolved reference.
