Why the tree exists

Generated code is easy.
Generated evidence is harder.

The tree treats every major decision as an artifact. Intent becomes intent.json. Scope becomes scope.json. Reference acquisition becomes reference.json. Missing evidence cannot be replaced with a confident guess.

Every node declares prerequisites and an output artifact. It also carries a model class, response budget, schema, failure behavior and downstream consumers. The next node only runs when its declared inputs exist.

Reference acquisition

The tree uses tools before it writes.

Reference Load follows an explicit acquisition chain. Observed data stays separate from inference.

01

SPA-Ripper

Recovers public SPA assets and dynamic chunks. It follows CSS dependencies, manifests and workers, plus client-side routing. The reference policy gives it first choice for public pages.

spa-ripper clone https://target.example -o ./clone
frontend evidence
02

SiteMap-X

Reconciles routes and assets with runtime requests. It maps endpoint literals, forms and technology fingerprints and can add rendered screenshots.

sitemapx https://target.example --render --out ./crawl
route map
03

api-researcher

Profiles discovered endpoints for authentication and pagination. It records versioning, rate-limit signals, error shape, CORS behavior and response structure using conservative probes.

apiresearch --endpoints endpoints.txt --out ./api_research
API behavior
04

SlopMonster

Scores visible copy for AI vocabulary and stock sentence shapes. It also checks punctuation cadence, repeated three-part rhythm and unsupported proof. A failing score can block the build.

python tools/deslop.py index.html
copy gate

Execution order

Five tiers, each with a different job.

Tier 1

Foundation

Intent and suitability establish the request. Scope and the system model follow. Reference loading leads into file structure, then manifest/scaffold work and prompt composition.

Normative contracts

Rules that can stop the build.

The contracts are enforcement boundaries, not style suggestions.

01

Wiring

Imports, images, routes and API calls must resolve. Tokens, environment variables, locale keys and components are checked before a file lands.

02

Integrity

Types and state are checked. Assets and promises are checked too, alongside listener/leak behavior and accessibility. Implementation details do not get to rot quietly.

03

Hardening

Default-deny auth covers secrets, headers, CSRF, validation and CORS. Dependency policy, timeouts and logging are checked separately. Cookie/webhook controls, SSRF protections and production hygiene are also enforced.

04

Completeness

system.json and manifest.json define scope. A required pending artifact means the product is not complete.

05

Consistency

Pages stay on one layout and token system. Shared components keep spacing consistent, while motion stays inside approved rules.

06

Repair

Failures become minimal reproductions and regression cases. Only the failed tool is patched. Public contracts do not change silently.

Reference discipline

Evidence is a first-class input.

A fixture is not a scrape. A screenshot is not an API contract. A route literal is not proof that a feature works. The tree records acquisition method and provenance. It also records confidence, blockers and unresolved items so downstream nodes know what was observed.

Node 23b

The final ship gate is allowed to say no.
